# Big Data Analytics & Supply Chain Optimisation System

## Overview
This project focuses on descriptive, diagnostic, predictive, and prescriptive analytics using large-scale datasets. The system was developed as part of the Big Data Analytics module and demonstrates practical applications of data analysis, machine learning, NoSQL databases, PySpark, and optimisation modelling.

The project analyses:
- 100,000+ e-commerce sales records
- 1,000,000+ loan application records
- Supply chain demand and pricing datasets

The system also includes a multi-period supply chain optimisation model designed to maximise operational profit under business constraints.

---

## Features

### Descriptive Analytics
- Summary statistics and data exploration
- Correlation analysis
- Heatmap visualisation
- Sales trend analysis

### Diagnostic Analytics
- Anomaly detection using Z-score
- Root cause analysis
- Product return investigation
- Large-scale PySpark processing

### NoSQL Database
- JSON document management
- CRUD operations
- MongoDB/TinyDB integration
- Image insertion into NoSQL database

### Predictive & Prescriptive Analytics
- Demand forecasting
- Sales price prediction
- Multi-period supply chain optimisation
- Profit maximisation using Gurobi solver
